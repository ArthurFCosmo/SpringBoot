## Primeiras migrations

As primeiras migrations do projeto serviram para definir as tabelas das nossas entidades. Cada entidade recebia uma migration individual. Como são 5 entidades, foram migrations da V1 até a V5
## Especialidades (v1)

```SQL
CREATE TABLE tb_especialidades (

    id BIGINT AUTO_INCREMENT,

    nome VARCHAR(100) UNIQUE NOT NULL,

    descricao VARCHAR(255),

  

    PRIMARY KEY (id)

);
```

### Medicos (v2)

```SQL
CREATE TABLE tb_medicos (

    id BIGINT AUTO_INCREMENT,

    nome VARCHAR(100) NOT NULL,

    crm VARCHAR(9) UNIQUE NOT NULL,

    email VARCHAR(255) UNIQUE NOT NULL,

    telefone VARCHAR(20) NOT NULL,

    ativo BOOLEAN NOT NULL DEFAULT TRUE,

    id_especialidade BIGINT NOT NULL,

  

    PRIMARY KEY (id),

    CONSTRAINT fk_medico_especialidade FOREIGN KEY (id_especialidade) REFERENCES tb_especialidades(id)

);
```

## Pacientes (v3)

```SQL
CREATE TABLE tb_pacientes (

    id BIGINT AUTO_INCREMENT,

    nome VARCHAR(100) NOT NULL,

    cpf varchar(11) NOT NULL UNIQUE,

    email varchar(255) NOT NULL UNIQUE,

    telefone varchar(20) NOT NULL,

    data_nascimento DATE NOT NULL,

    ativo BOOLEAN NOT NULL DEFAULT TRUE,

  

    PRIMARY KEY (id)

);
```

### Consultas (v4)

```SQL
CREATE TABLE tb_consultas (

    id BIGINT AUTO_INCREMENT,

    data_hora DATETIME NOT NULL,

    status VARCHAR(20) NOT NULL,

    observacoes VARCHAR(255),

    id_medico BIGINT NOT NULL,

    id_paciente BIGINT NOT NULL,

  

    PRIMARY KEY (id),

    CONSTRAINT fk_consulta_medico FOREIGN KEY (id_medico) REFERENCES tb_medicos(id),

    CONSTRAINT fk_consulta_paciente FOREIGN KEY (id_paciente) REFERENCES tb_pacientes(id)

);
```

### Prescricoes (v5)

```SQL
CREATE TABLE tb_prescricoes (

    id BIGINT AUTO_INCREMENT,

    descricao VARCHAR(255) NOT NULL,

    medicamentos VARCHAR(255),

    data_emissao DATE NOT NULL,

  

    id_consulta BIGINT NOT NULL,

  

    PRIMARY KEY (id),

    CONSTRAINT fk_prescricao_consulta FOREIGN KEY (id_consulta) REFERENCES tb_consultas(id)

);
```
